Tracking

–

While you aim, the server guesses which object you mean inside the dashed box and outlines it (green: likely, yellow: maybe). With "Snap to the object", Lock on takes that tight box, so the tracker learns the object and not the background; otherwise the whole dashed box. The board then reports the target's centre (x, y in the live frame), size and confidence with every frame, and keeps the lock through movement, rotation, deformation and size changes. A hardware button on the pin (to GND, with a pull-up to 3.3 V) locks on or stops.

SD card

Use "Mount again" after swapping the card. Format erases everything on it.

Capture

The board saves the photo as 640×480 tiles. This server joins them and saves full.jpg next to them on the card. VGA and QVGA are a single picture that the board saves as full.jpg itself, with no joining. Sizes up to 1280×960 show the camera's whole view. Larger sizes are a native-pixel crop from the centre of the sensor (up to 25 tiles, about 30 s).
